# MAKA_template

Visual snapshot of the Maka Studio web mock — the same layout used for the desktop exe mock. This folder is **not a release**. It preserves the HTML, CSS, and script from before the `/stream` controls were wired to capture, WHIP, and recording.

Open `index.html` in a browser (double-click the file, or serve this folder). The program monitor shows the hero artwork. Scene rows are filled in by `stream.js`. Fonts are local (`fonts/`); images are `program-poster.jpg` and `stream-thumb.jpg`.

Do not treat this directory as the live studio. The wired page lives in `site/stream/`.
