Relay + Web Studio

This path is for the original relay setup: install the standalone relay executable, then use the browser-based capture studio with the Chrome extension workflow. If you want the new all-in-one app, use Maka instead.

  1. Step 1 — Relay

    Download and run MAKA.relay (MAKArelay.exe). It listens on 127.0.0.1:38473.

  2. Step 2 — Web studio

    Open the Maka web studio in Chrome. Capture runs in the browser; the relay handles encode + WHIP.

  3. Step 3 — Go live

    Connect your stream keys in the web UI and publish through the local relay — same as before v0.2.
